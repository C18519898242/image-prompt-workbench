# Image Prompt Workbench 生成工作台设计

## 1. 文档状态

- 状态：已确认设计，待实现
- 日期：2026-08-02
- 目标：实现一个用于准备单次图片生成任务的生成工作台
- 本次范围：只实现生成工作台的前端交互，不接入真实生图服务

## 2. 视觉基准

生成工作台以现有设计稿为布局和视觉基准：

- 参考图：`docs/superpowers/specs/assets/image-prompt-workbench-generation-workspace.png`
- 主题：浅色
- 页面背景：白色或极浅灰色
- 面板：白色、浅灰色细边框、轻量阴影
- 主文字：近黑色
- 主按钮：黑色背景、白色文字
- 次要按钮：白色背景、黑色边框和文字
- 圆角：统一使用小圆角
- 图片：保持原始比例，使用 `contain`，不裁剪、不拉伸
- 动效：只保留图片切换和按钮反馈，不做装饰性循环动画

## 3. 页面入口与任务边界

用户从已有提示词选择入口进入生成工作台时，页面带入：

- 当前提示词标题
- 当前提示词文本
- 当前提示词的示例图

提示词示例图只用于理解效果，不自动加入生成参考图。用户编辑的是当前任务草稿，不修改原始提示词内容。

本次点击“开始生成”只在前端创建一次本地演示提交反馈：

- 不调用真实生图接口
- 不上传参考图到服务器
- 不展示虚构的生成进度或生成结果
- 不跳转其他页面
- 不保存任务和历史记录

## 4. 页面结构

### 4.1 顶部区域

- 提供“返回”入口
- 显示当前提示词标题

### 4.2 左侧：提示词示例图

- 使用固定的 4:3 横向展示区
- 一次只显示一张示例图
- 提供“上一张”和“下一张”按钮
- 显示“当前序号 / 总数”，例如 `2 / 4`
- 图片使用 `contain` 完整显示，不裁剪、不拉伸
- 竖向长图在展示区内居中，左右保留自然留白
- 切换图片时展示区尺寸和按钮位置保持不变
- 显示“仅用于理解效果”提示
- 本次不增加全屏阅读、内部滚动或缩放

如果当前提示词没有示例图，展示区显示简单空状态，但不影响提示词编辑。

### 4.3 左侧：提示词

- 使用一个可直接编辑的多行文本框
- 进入页面时填入原始提示词文本
- 修改只影响当前任务草稿
- 不提供清空按钮
- 不显示字符数统计

### 4.4 右侧：生成参考图

生成参考图是用户主动加入本次任务的图片，与只读的提示词示例图明确区分。

- 标题为“生成参考图（可选）”
- 使用 2 列网格
- 缩略图使用 4:3 比例
- 默认展示 4 个位置
- 提供同样比例的“添加”卡片
- 点击“添加”后选择本地图片，并立即显示浏览器本地预览
- 每张已添加图片提供单独的删除入口
- 不同长宽比图片统一使用 `contain`，避免裁剪
- 图片数量增加时只让网格自然换行，不增加数量管理面板、内部滚动或展开管理
- 本次不实现拖拽上传、裁剪、图片编辑和上传进度

### 4.5 右侧：生成参数

提供设计稿中已经确认的基础参数：

- 模型
- 比例
- 分辨率
- 生成数量
- 思考级别
- 可折叠的“高级参数”入口

默认值沿用设计稿示例：

- 模型：`Nano Banana 2`
- 比例：`4:3`
- 分辨率：`1K`
- 生成数量：`1`
- 思考级别：`中等`

本页面不设置输出格式参数。高级参数只保留设计稿中的折叠入口，不自行增加未确认的字段。

### 4.6 唯一的提交按钮

- 页面只保留一个全宽黑色“开始生成”按钮
- 按钮提交当前提示词草稿、参考图和生成参数
- 提示词为空时按钮不可用
- 点击后按钮附近显示“已创建本地生成任务（演示）”反馈
- 提交后保留当前提示词、参考图和参数
- 不展示假进度、假结果或第二个生成按钮

## 5. 页面状态

| 状态 | 页面显示 | 主按钮 |
| --- | --- | --- |
| 正在读取当前提示词 | 简短加载提示 | 不可用 |
| 没有可用提示词 | 空状态和返回入口 | 不可用 |
| 已选择提示词 | 示例图、提示词、参考图区域和参数 | 可用 |
| 提示词为空 | 保留页面内容 | 不可用 |
| 已添加参考图 | 显示参考图缩略图 | 可用 |
| 本地提交完成 | 保留全部内容并显示就地反馈 | 可再次提交 |
| 读取失败 | 相关区域显示错误和返回入口 | 不可用 |

错误信息显示在相关内容附近，不使用全局弹窗替代上下文提示。

## 6. 数据与实现边界

页面只维护当前任务需要的临时内容：

```text
当前提示词卡片
当前提示词草稿
当前提示词示例图索引
当前生成参考图列表
生成参数
本地提交反馈与错误信息
```

参考图只在浏览器本地生成预览，不写入服务器。离开页面或刷新后，当前任务草稿和本地预览不保留。

页面使用已有提示词卡片数据，不修改原始提示词卡片数据结构，不新增后端接口。

按钮、输入框和下拉框使用浏览器默认行为，不增加自定义键盘快捷键。

## 7. 验收标准

- 页面布局与生成工作台设计稿一致
- 页面只有一个“开始生成”主按钮
- 提示词示例图一次只显示一张，并支持上一张、下一张和序号显示
- 示例图不会被裁剪或拉伸，竖向长图能在固定展示区完整显示
- 提示词可以直接编辑，且没有清空按钮和字符数统计
- 生成参考图位于右侧，支持本地添加、缩略图预览和单独删除
- 生成参考图和提示词示例图在视觉上明确区分
- 生成参数包含模型、比例、分辨率、生成数量、思考级别和高级参数入口
- 提示词为空时“开始生成”不可用
- 点击“开始生成”后仍停留在当前页面，并显示本地提交反馈
- 不调用真实生图接口，不上传图片，不展示生成结果
- 不新增与生成工作台无关的页面或功能

- 未经确认的高级参数字段
- 自定义键盘快捷键
